# Corpus hierarchy construction and maintenance

## Intent
Extend the existing DecisionRAG backend with a usable offline hierarchy pipeline for structured and unstructured corpora. This implements the user's two construction cases and addresses maintenance, description provenance, granularity diagnostics and multilingual text; it does not claim an automatically optimal tree or reproduce paper benchmark quality.

## Contracts
- New `hierarchy_formats.py`: `normalize_document(doc: dict, *, infer_layout: bool = False) -> dict` returns copied JSON document with stable nonempty string id, title, contents (normalized visible text), url, metadata, `sections: list[{heading: str, text: str}]`, `structure_path: list[str]`, and `structure_source: str`. Source path precedence metadata.hierarchy_path (list of labels), metadata.topic/product/category (in that order, combine nonempty), URL host + directory segments (exclude final path component), empty. Validate fields. Recognize explicit sections, HTML h1-h6 (remove script/style), Markdown/setext headings, optional conservative layout headings; plain text stays Body. Do not guess HTML merely because code contains angle brackets: metadata.format/content_type or convincing HTML block tags. `split_passages(text: str, *, max_words: int, max_chars: int) -> list[str]` preserves all non-whitespace content, bounds words and chars, supports no-space CJK. `first_sentence(text: str) -> str` supports .!?。！？ and bounds pathological no-punctuation text.
- New `hierarchy.py`: dataclasses `HierarchyConfig(mode='auto', target_cluster_size=100, max_cluster_size=200, n_clusters=None, random_state=42, infer_layout=False, embedding_model='intfloat/multilingual-e5-base', description_model=None)` with validation and serializable `HierarchyArtifact`. Artifact fields: schema_version=1, config dict, documents list of normalized documents, groups list of dict `{id,parent_id,label,description,description_source,document_ids,centroid?}`, assignments dict doc-id->group-id, fingerprints dict id->hash, vectors dict id->list[float], diagnostics dict. Group document_ids are direct members (internal semantic groups may have children). IDs stable across incremental updates where membership unchanged. No timestamps required for deterministic artifacts.
- `build_hierarchy(docs, config=None, *, embedder=None, describer=None, previous=None) -> HierarchyArtifact`. Embedder `encode(texts: list[str]) -> numpy.ndarray`; describer `describe(label: str, documents: list[dict]) -> str`. In auto mode reuse available structure, cluster only documents with no path; structure mode unstructured docs go into an explicitly marked fallback group. cluster mode clusters all docs. Reuse unchanged normalized docs, vectors and assignments from compatible previous artifact; changed/new docs assigned to nearest existing semantic leaf centroids, overflow split locally, deletes removed. Incompatible embedding/config changes require explicit full rebuild (previous omitted). Embed title + first sentence only, normalized E5 prefix in adapter. Full build deterministic sklearn KMeans with n_init explicit. Auto count ceil(unstructured_count/target_cluster_size), explicit n_clusters supports NQ 1000. Enforce max_cluster_size including identical-vector degenerate clusters, via deterministic balanced overflow partition with diagnostic warning. Group descriptions generated offline, persisted with source, cached by unchanged membership/content; deterministic extractive title fallback when no describer. Dirty groups only are described again. Diagnostics include counts/sizes/depth/empty titles/heuristic use/oversize and changed/new/deleted/reused document counts; warnings identify fallback descriptions and routing limitations. Include actionable rebuild recommendation on significant churn.
- `HierarchyArtifact.save(path)` atomic JSON replacement, `.load(path)` validates schema, documents, group parent graph, unique IDs, assignments, vector dimensions/finite values and no orphan/duplicate membership. Reject corrupt artifacts before serving. Deep-copy or avoid mutation of input/previous artifacts.
- New `hierarchy_models.py`: lazy local `SentenceEmbedding` with SentenceTransformer(trust_remote_code=False), `encode()` normalized vectors and E5 passage prefix; lazy `LocalHierarchyDescriber` using local Transformers chat template + deterministic generate, bounded sampled title/first-sentence context, trust_remote_code=False, device explicit, output nonempty/finite length. Generation is offline only. No hosted model call. Tests no network/model weights.
- New `hierarchy_cli.py`: subcommands build/update/inspect. Build/update require corpus spec or JSONL path, output. Update takes previous artifact and full current corpus snapshot (missing IDs are deletions). `--mode`, `--embedding-model`, `--description-model`, `--target-cluster-size`, `--max-cluster-size`, `--clusters`, `--infer-layout`, `--device`; inspect prints artifact diagnostics. No embedding model loaded for structure-only corpora. Artifact config must store encoder identity and summary generator identity. Support injection in unit tests and subprocess --help.
- Existing DecisionRetriever gains optional keyword `hierarchy=None`. When provided, construct actual group parent hierarchy above existing document/section/passage nodes, use stored descriptions and normalized sections. Existing no-artifact behavior remains compatible. `DecisionRetrieverConfig` adds max_passage_chars=1200 and per-kind optional `beam_widths: dict[str,int]` for group/document/section; default beam unchanged. Navigating uneven depth trees must not discard shallow leaves or compare different semantic kinds as the same stage: expand groups until exhausted while retaining early documents, then normal document/section/passage stages. Group pruning retains per-level global group budget; documents wait for all groups to resolve. Bounded section fanout via format passages and inspect diagnostics; no quality claim.
- Active ACL filters must never expose automatically generated descriptions containing hidden content. For artifact groups rebuild query-time routing descriptions from visible descendant document titles instead of persisted summaries. Existing unrestricted fast path remains. Keep stage trace meaningful.
- Retrieval server adds mutually exclusive `--hierarchy` alongside corpus sources, loads and validates offline artifact without embedding/describer initialization, passes artifact to retriever. Existing CLI/tests unchanged.

## Safety and quality boundaries
Heuristic section recovery opt-in; source/provenance and warnings persisted. HTML parser removes noncontent scripts/styles. No remote fetching of document URLs. Supported input formats JSONL documents containing plain text, Markdown or HTML; binary PDF/Office ingestion remains existing connector responsibility. Multilingual model default; exact English NQ recipe explicitly configured e5-base-v2, --clusters 1000, local description model. Tree report measures structural quality, not retrieval recall. No tuning on evaluation test labels. No deployment or pushing without a concrete requested PR action.
