# Docs sync: #672–#690

The docs are a running mirror of the codebase. This sync corrects the behavioural
claims invalidated by the PRs merged since the last full sync (#668: README #669,
guides #671), and fills reader-visible gaps.

## Scope

- **#673, #676:** already synced in their own PRs. Verified only.
- **#677:** AgenticRAGLoop. Original query first; blank and duplicate variants
  dropped; a shared, bounded evidence preview (`evidence_preview_chars`, 3000,
  code-level only); overflow follow-ups stay eligible.
- **#678:** leading-intent fallback routing; one shared budget for working-memory
  summary and recent messages (the newest message always kept); tool-argument
  preflight (`invalid_arguments`, rejected before approval).
- **#679:** two-stage reranking keeps `max(pre_filter_top_n, top_k)` candidates
  and runs sync stages off the event loop; optimization candidates are scored on
  their own services; RRF counts a document once per source.
- **#680–#690:** cross-doc consistency for search-source categories, source sites,
  multi-category `domains`, opt-in `auto`, and the two evaluation CLIs.

Out of scope: reorganisation, style, and internal refactors readers cannot observe.

## Method

Five parallel agents on disjoint file sets, each verifying every claim against
code. The controller spot-checked the riskiest values. Scripted checks: relative
links and anchors over README, CLAUDE.md and every guide; the architecture tree
compared with `git ls-files`.
